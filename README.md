# Документация информационной системы «Яга»

## О проекте

Данный репозиторий содержит комплект технической документации для информационной системы **«Яга»** — модульной платформы для управления проектами, задачами и знаниями в командах.

> **Внимание:** документация разработана на основе **демо-версии** системы «Яга» в рамках тестового задания. Описанные функции и интерфейс соответствуют демонстрационному доступу, предоставленному на этапе тестирования.

## Ключевые возможности системы

- **Управление задачами** — создание, назначение исполнителей, установка сроков, приоритетов и зависимостей
- **Kanban-доски** — визуальное отслеживание статусов задач с поддержкой перетаскивания и фильтрации
- **База знаний** — создание и редактирование статей с версионированием, тегированием и полнотекстовым поиском
- **Ролевая модель** — разграничение прав (администратор, руководитель, исполнитель, наблюдатель)
- **Уведомления** — email, мессенджеры, внутри системы
- **Отчётность** — аналитика по задачам, срокам, загрузке сотрудников
- **Интеграции** — LDAP/Active Directory, SAML, OIDC, REST API, SMTP, Telegram

# Комплект программной документации ИС «Яга»

## О проекте

Репозиторий содержит комплект технической документации для информационной системы «Яга» — модульной платформы для управления проектами, задачами и знаниями в командах.

> **Внимание:** документация разработана на основе **демо-версии** системы «Яга» в рамках тестового задания. Описанные функции и интерфейс соответствуют демонстрационному доступу, предоставленному на этапе тестирования. Руководство администратора разработано по ГОСТ 19.503-79 как ближайшему аналогу: отдельного вида документа ЕСПД «руководство администратора» не существует.

## Ключевые возможности системы

- **Управление задачами** — создание, назначение исполнителей, установка сроков, приоритетов и зависимостей
- **Kanban-доски** — визуальное отслеживание статусов задач с поддержкой перетаскивания и фильтрации
- **База знаний** — создание и редактирование статей с версионированием, тегированием и полнотекстовым поиском
- **Ролевая модель** — разграничение прав (администратор, руководитель пространства, исполнитель, наблюдатель)
- **Уведомления** — email, мессенджеры, внутри системы
- **Отчётность** — аналитика по задачам, срокам, загрузке сотрудников
- **Интеграции** — LDAP/Active Directory, SAML, OIDC, REST API, SMTP, Telegram
